# Security warning

The credentials supplied in the chat should be treated as **exposed** because they were pasted into a conversation. Before deploying this repository, revoke/rotate the Telegram bot token in BotFather and regenerate/replace any API credentials you consider compromised.

Do not put real API_HASH or BOT_TOKEN values into `main.py`, `.env.example`, README, Git history, or a public repository. Use Railway environment variables instead.
